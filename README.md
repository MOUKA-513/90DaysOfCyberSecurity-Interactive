## 🚀 Features

- 📆 **95 days of structured learning** — 90 core days + 5 career-focused days
- 🔍 **Phase-based filtering system** — focus on Network+, Linux, Python, Tools, Cloud, or Career
- 🔗 **Curated learning resources** — every day includes a direct link to a useful video, tutorial, or lab
- 💎 **Modern responsive UI** — glassmorphism design with smooth animations
- ⚡ **Lightweight & fast** — built with vanilla HTML, CSS, and JavaScript
- 📱 **Fully mobile-friendly** — learn from any device
- 🎯 **Beginner-friendly progression** — move from fundamentals toward practical cybersecurity skills
- 🧪 **Hands-on learning** — includes practical tools, labs, and real-world concepts

## ▶️ Usage

1. Open `index.html` in any modern browser.
2. Use the **phase filter buttons** to display the learning phase you want.
3. Browse through the daily learning cards.
4. Click the **resource button** on any card to access that day's learning material.
5. Follow the roadmap sequentially or jump between topics according to your goals.

The roadmap is organized by day, making it easy to maintain a consistent learning routine.

## 📚 Learning Approach

This roadmap follows a **progressive, hands-on learning strategy**.

### 🧱 Step 1 — Build the Fundamentals

Start by understanding:

- Computer networking
- TCP/IP
- OSI model
- Network protocols
- IP addressing
- Subnetting
- DNS
- HTTP/HTTPS
- Basic security concepts
- Authentication and authorization

### 🐧 Step 2 — Learn Linux

Build practical Linux skills including:

- Linux command line
- File systems
- Permissions
- Users and groups
- Processes
- Networking commands
- Bash basics
- System administration

### 🐍 Step 3 — Learn Python

Use Python to develop automation and scripting skills:

- Python fundamentals
- Variables and data types
- Conditions and loops
- Functions
- Files
- Modules
- Networking
- Automation
- Security-related scripting

### 🔎 Step 4 — Work With Security Tools

Move into practical cybersecurity concepts and tools such as:

- Traffic analysis
- Packet inspection
- Git
- ELK Stack
- Logging
- Monitoring
- Security analysis
- Incident investigation

### ☁️ Step 5 — Explore Advanced Topics

Continue into:

- Cloud security
- Ethical hacking
- Penetration testing
- Security tools
- Vulnerability assessment
- Real-world attack techniques

### 💼 Step 6 — Prepare for Your Career

The final days focus on becoming job-ready:

- Resume preparation
- LinkedIn optimization
- Portfolio building
- Job searching
- Interview preparation
- Cybersecurity career planning

## 🐛 Troubleshooting

### ❌ Page not loading properly

Make sure the following files are located in the same directory:

```text
index.html
styles.css
script.js
```

Also verify that the CSS and JavaScript files are correctly referenced inside `index.html`.

### ❌ Resource links are not working

Check the URLs inside `script.js`.

External websites may occasionally:

- Change their URLs
- Remove content
- Move tutorials
- Make resources unavailable

Simply update the affected URL inside `script.js`.

### ❌ Styling looks broken

Make sure you are using a modern browser such as:

- Chrome 90+
- Firefox 88+
- Edge 90+
- Safari 14+

If the problem persists, clear your browser cache and reload the page.

### ❌ Icons or fonts are not loading

Check your internet connection.

The project uses external resources such as:

- Font Awesome
- Google Fonts

If these resources are unavailable, the main application should still function, but some visual elements may not appear correctly.

## 💡 Why This Project?

Most cybersecurity roadmaps are either too vague or overwhelming.

This project was created to provide a **simple, structured and practical daily path** for people who want to learn cybersecurity.

### 🎯 No Fluff

Every day has a specific topic or learning objective.

### 🔗 Curated Resources

Learning materials are selected to help you quickly find useful content without spending hours searching.

### 📈 Real Progression

The roadmap gradually moves from:

```text
Fundamentals
↓
Networking
↓
Linux
↓
Python
↓
Security Tools
↓
Traffic Analysis
↓
ELK Stack
↓
Cloud Security
↓
Ethical Hacking
↓
Career Preparation
↓
Job Ready 🚀
```

The goal isn't just to watch videos.
